# PLAN

Topic order and problem shortlist. Static reference — progress lives in each problem's frontmatter (`npm run stats`, planned), not here.

- Order: structures → techniques. Inside a topic, work top to bottom: Easy → Medium → optional Hard.
- **Gate:** leave a topic once a Medium is solved without hints. Skip ahead or add problems freely; the shortlist is a suggestion, not a quota.
- Each problem appears once, in the topic where it is first introduced. Reviews bring everything back later.
- Numbers, titles and difficulties were written from memory — verify on LeetCode before creating a folder.

E = Easy · M = Medium · H = Hard
